# 🚀 Kids Weekdays Adventure

A colorful, interactive, touch-friendly web game designed to help young children learn the days of the week through musical sound associations and sequence puzzles.

---

## 🎮 Learning Features
1. **Musical Day & Number Combination (Level 1)**:
   - Each number (1 to 7) has a distinct musical bell note and rhyme (e.g., *"1 is Monday!"*, *"2 is Tuesday!"*).
   - Tap any number to hear its sound, or press *"Play All 7 Days"* to hear the full rhythm.
2. **"What's Next?" (Level 2)**:
   - Hypothetical scenarios: *"Let's say today is Tuesday! What day comes next?"* (prevents confusion with the real day of the week).
   - Clean choice cards with no numbers so the child cannot cheat by matching numbers.
3. **Day Train (Level 3)**:
   - Load train cars 1 to 7 in order from first to last.
4. **Australia Weekday Toggle**:
   - Easily switch between **Monday** (Australian school standard) and **Sunday** as the start of the week.
